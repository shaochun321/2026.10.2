# MFS0-E2 理论、方程、槽状态与资格范围

## 1. 学习对象

历史 i 在时刻 s 有一次入口，被入口门接受。对这次经历，外部评价目标定义为：

Y = 1{ 在 [s, s+H) 内，后续通道有被入口门接受的事件 }，其中 H = τ_T·ln(V_D/θ_hi) = 1.039721 s。

- 预测 p̂ 取入口所在步开始时的读支路输出，即本步输入尚未处理时的旧状态：p̂ = I_read,i / I_fs。
- 学的是"有限时间窗内的发生概率"，不是因果归属。同一个 L 落在两个重叠窗口里时，两边的 Y 都记为 1。

## 2. 三种状态

| 状态 | 物理对象 | 生命周期 |
|:--|:--|:--|
| 长期载体 z_c = 1 − w_c | 每条历史一个 Memristor（共享对照中三条历史共用 1 个） | 全流 |
| 经历槽 (T_ir, O_ir) | 每条历史 2 个槽，每个槽有 2 个电容 | 接纳 → 观察 → 结算 → 回收 |
| 预测记录 P | PredictionPort 中不可变的 PredictionRecord | 只作输出与评价 |

## 3. 每步顺序（冻结）

1. **读出**：从旧载体计算每条历史的读电流。读支路相互独立，不受观察窗门控，也不跨历史求和。
2. **接纳**：用旧的槽状态判断空闲，free = (T < θ_lo) ∧ (O < O_free)，由两个比较器给出。选槽规则为 A_ir = b_Wi · free_ir · Π_{q<r}(1 − free_iq)，即按固定优先级取第一个空闲槽。没有空闲槽时记为 CAPACITY_REJECTED，不覆盖已有经历。
3. **T**：被接纳的槽经开关置位到电源轨，然后 RC 泄漏；用 exact relax 求解。
4. **O**：只有 b_L 为真且本槽窗口比较器为真（用本步刚更新的 T 判断 T ≥ θ_hi）时才置位；随后按 τ_o = 30 s 保持；当 T < θ_lo + Vth 时由本槽复位支路清除。复位只看本槽自己的 T，不等其他历史空闲。
5. **写入**：所有支路电导都用同一个旧载体状态计算。每个载体节点只求解一次：

   V_M = R·ΣG_jE_j / (1 + R·ΣG_j)，I_M = ΣG_jE_j / (1 + R·ΣG_j)，其中 E_j = +V_write（UP 支路）或 −V_write（DOWN 支路）。

   每步对每个载体只调用一次 `Memristor.update`，传入带符号的净电荷，调用侧乘 dt（DEG-025）。各支路自己的电荷按 I_j = G_j(E_j − V_M) 单独记账。

## 4. 并发写入

理想参照为 ż_c = Σ_r λ_r(t)(q_r − z_c) = B(Q − z)，其中 B = Σλ，Q = Σλq / B；B = 0 时不写入。

- 单槽剂量 λ0 = −ln(0.9)/S，S = τ_T·ln(θ_hi/θ_lo) = 1.805959 s。
- 方案 §6.2 的例子（z0 = 0.4，两次经历一次观察到 L、一次没观察到）：节点结果 0.41841，参照 0.41901，理想同时作用 0.419。若按软件顺序依次写入，结果是 0.414（先 UP）或 0.424（先 DOWN）。

## 5. 数学性质（理想参照成立；节点实现按经验验证）

- **区间保持**：z 始终在 [0,1] 内。
- **收缩**：两条轨迹之差按 exp(−∫B dt) 收缩。
- **无资格不写**：某载体的所有结算支路都关闭时，不调用 update，这一点由结构保证。
- **误差界**：|e(t)| ≤ e^{−A(t)}|e(0)| + ∫ e^{−[A(t)−A(s)]}|r(s)| ds。这只提供分析框架；实际残差用有限网格测量，属于经验结果，不是定理。

## 6. 登记的理想化（TIER-2）

- **L1**：差分节点理想。
- **L2**：戴维南电源轨 + 串联电导链；每个载体节点单独求解。
- **L3**：读出不扰动载体。
- **L4**：把 conduct()/1 V 当作电导使用。
- **C1**：窗口门和空闲判定用理想比较器，建立在 MOSFET.conduct() 的硬截零（DEG-019）之上。这是结构修订 R1：线性窗口 FET 在观察窗最后约 7 ms 只能部分置位 O，会使窗口边界偏离独立时间参照。

## 7. 资格范围

- **R 路径**：CAUSAL_REPLAY_REFERENCE + TEMPLATE_TRANSLATION（冻结模板为 W = cal_C3_m、LATER = s23_ov）。
- **L 路径**：项目现有的 BaseGenerator.feed → collector → CollectorBoundaryPort.spike_output → PhysicalEntryGate.step。刺激回调只返回当前值。这条路径证明的是"接入可运行、不读未来"，不单独授予长期预测收益资格。
- **历史身份**：由预先接好的输入路径决定，系统不会自动创造历史类别。
- **容量**：每条历史 2 个槽。压力层的注入直接作用在入口脉冲契约上，不声称上游已经能产生这样的输入。
- **L 通道**：只有一个，同通道最小间隔约 1.85 s。结果是"外来 L"会抬高低概率历史的实现率，冲突也会压低高概率历史的实现率（开发流中约 0.72 对 0.42）。评价一律使用实际的 Y，而不是生成器的 p。

## 8. 接口契约

- `MemoryCore.step(b_W, b_L, dt)`：只接收当前入口脉冲和 dt。
- `PredictionPort`：每个被入口门接受的 W 输出一条不可变的 PredictionRecord，字段为 t、tick、path、p_hat、horizon_s、status、slot、free_slots_before。
- `ThresholdConsumer`（阈值 0.65）：只读取记录，不读 w，不读评估真值，也不写回。
- 调用样例：`example_interface.py`。
