## 二、误差预算分配（v3 §5）

**总误差公式**：
```
δ_total = δ_obs + δ_comp + tanh(β/4) + ε_step
```

| 项 | 符号 | 分配值 | 来源 |
|:---|:---|:---|:---|
| 观察态误差 | δ_obs | 0.015 | v3 §5.2 q-y 偏差（r=1.05 → 0.012197） |
| 互补门误差 | δ_comp | 0.020 | v3 §5.3 互补误差界（20 万样本最坏 0.0299，界 0.0316） |
| 增益偏差 | tanh(β/4) | 0.010 | v3 §5.4 增益因子（β ≤ 0.04 → tanh(0.01) ≈ 0.01） |
| 数值积分误差 | ε_step | 0.005 | 保守估计（dt 三档检查后确定） |
| **总预算** | δ_total | **0.050** | **设计指标上界** |

**逐次乘积传播**（v3 §5.2）：
- 观察态：δ_q = δ_obs + δ_comp + tanh(β/4) = 0.015 + 0.020 + 0.010 = 0.045
- 学习率：(1+δ_q) · (1+δ_comp) − 1 ≈ δ_q + δ_comp = 0.065
- 终态偏差：α · (δ_q + δ_comp) + ε_step ≈ 0.05（α ≈ 0.5 时）

**约束**：
- r = V_hi / V_lo ∈ [1.00, 1.10]（v3 §5.2，r=1.05 推荐）
- ρ ∈ [0, 0.85]（候选 P 幅度约束，v3 评判 §2.1）
- ρ ∈ [0.5, 0.7]（D0 推荐，优先候选 P）

## 六、成本草案（v3 §7A）

**单次经验成本**：
```
N_cycle = ⌈(T_obs + T_write + T_clear + T_gap) / dt⌉
```

**解析估计**（假设 ρ=0.6, dt=1 ms）：
- T_obs ≈ 3000 步（写入可达窗中点）× 1 ms = 3.0 s
- T_write ≈ 722 步（E0 NEAR 实测）× 1 ms = 0.722 s
- T_clear ≈ 99 × τ_on（假设 τ_on = 1.0 s）= 99.0 s
- T_gap ≈ 1.0 s（复位间隔）
- **N_cycle ≈ 103,722 步 ≈ 103.7 s**

**短程映射总成本**（8 个 p × 50~100 次）：
- 400~800 次经验 × 103.7 s = 41,480~82,960 s ≈ **11.5~23.0 h**

**⚠️ 超预算风险**：主实验预算 120 分钟 = 2 h，短程映射成本估计 11.5~23.0 h **超出 5.75~11.5 倍**。

**修正方案**：
1. pilot 短程测速（阶段 B 后立即执行）
2. 调整 p 采样点（8 个 → 4~5 个）
3. 减少每个 p 的经验次数（50~100 → 20~30）
4. 优化 T_clear（如果 ρ 接近 0.85，比值可降至 1.01）
