## 三、状态电容动力学（候选 P：被动负载）

**节点方程**（v3 §3.1）：
```
C_s · dv_s/dt = I_in − I_out
I_out = v_s / R_L
```

ρ = R_S / (R_S + R_L) ∈ [0.5, 0.7]（D0 推荐）

**充电阶段**（V_in = V_D）：
```
v_s(t) = V_H · [1 − exp(−t/τ_on)]
V_H = (1−ρ) V_D = V_D · R_L / (R_S + R_L)
τ_on = R_L C_s
```

**放电阶段**（V_in = 0）：
```
v_s(t) = V_H · exp(−t/τ_off)
τ_off = (R_S + R_L) C_s
```

**平台输出**（v3 §3.1）：
```
v_∞ = V_H · x / (1+x) = (1−ρ) V_D · 99/100
```

**时间常数比**（v3 §3.1，修正 E-1）：
```
τ_off / τ_on = (1+x) / (1+ρx)
```

**幅度约束**（v3 评判 §4.1）：
```
v_∞ ≥ θ_FET = 0.3 V
(1−ρ) · 2.0 · 99/100 ≥ 0.3  =>  ρ ≤ 0.8485
```

## 四、结算逻辑（RC 计时器 + 门控）

**结算门1**（W1 历史）：
```
p1(t) = a1(t) · H(v_o − θ_settle)
```

H(x) = Heaviside 函数（实现为 MOSFET 阈值器）

**结算时间常数**（v3 §5 + E0 实测）：
```

**结算门2**（W2 历史）：
```
p2(t) = a2(t) · H(v_o − θ_settle)

## 六、C1 约束的重新理解

v3 §3.1 给出的公式是：
```
τ_off / τ_on = (1+x) / (1+ρx)
```

D0 原结论"R-2 必需"来自 E-1 错误假设 ρ=0（τ_off/τ_on = 100/1 = 100）。

v3 评判 §2.1 撤回 E-1，但**没有给出 C1 的新数值要求**。

**重新推导 C1**：

清除/建立要求是指：
- **建立时间** T_settle：从 0 充到 v_∞ · (1−δ_s) 的时间
- **清除时间** T_clear：从 v_∞ 放到 v_∞ · δ_c 的时间

v3 §3.1 给出：
```
T_settle = τ_on · ln(x / (1+x))
T_clear = τ_off · ln(x)
```

δ_s = δ_c = 0.01，x = 99：
```
T_settle = τ_on · ln(99/100) = τ_on · (−0.01005)  （负值！）
```

⚠️ **公式有误**。正确公式应该是：
```
v_s(t) = V_H [1 − exp(−t/τ_on)]
v_s(T_settle) = V_H · 99/100
```

解得：
```
1 − exp(−T_settle/τ_on) = 99/100
exp(−T_settle/τ_on) = 1/100
T_settle = τ_on · ln(100) = τ_on · 4.605
```

类似地：
```
v_s(T_clear) = V_H · exp(−T_clear/τ_off) = V_H · 0.01
T_clear = τ_off · ln(100) = τ_off · 4.605
```

因此：
```
T_clear / T_settle = τ_off / τ_on
```

**C1 的实际含义**：如果要求 T_clear 和 T_settle "相近"（同一数量级），则 τ_off/τ_on 应该接近 1，而不是 99。

**结论**：ρ=0.6 → τ_off/τ_on=1.656 是**合理的**，满足 C1。
