## 二、我方 E-1 的错误

### 2.1 撤回"普遍 99 倍"结论

我方评判 `MFS0-E1方案评判_2026-09-29.md` E-1 声称"被动负载下 T_clear/T_settle 的最小值普遍为 99"（δ_p = δ_s = δ_c = 0.01 时），并据此在 D0 中得出"R-2 复位支路为必需项"。

**该结论是错的。**

正确公式为 v3 §3.1：
```
τ_off/τ_on = (1+x) / (1+ρx)，ρ = R_S/(R_S+R_L)
```

我的推导隐含假设了 **R_S=0**（即 ρ=0），这是一个特殊情况，不具有普遍性。

当 ρ 接近 1 时（大内阻结构），比值可以接近 1（v3 反例：ρ=0.99 时比值为 1.01）。因此：
- 被动负载不一定需要 99 倍时间；
- R-2 独立复位支路不是无条件必需的。

### 2.2 代价与约束

v3 §3.2 明确指出：大内阻消除了时间冲突，但代价是**输出幅度很小**。反例中 V_H 只有 0.01 V，远低于 MOSFET 阈值 0.3 V。

这引出一个新的联合约束（v3 §3.2 和我方补充）：
```
V_H = (1−ρ)V_D,  平台输出 v_∞ = V_H · x/(1+x)
```

要保证下游状态门能被驱动（v_∞ ≥ θ_FET = 0.3 V），同时满足平台精度 x ≥ 99，就给 ρ 设定了上限。

若 V_D = 2.0 V，要求 v_∞ ≥ 0.3：
```
(1−ρ) · 2.0 · 99/100 ≥ 0.3  =>  ρ ≤ 0.8485
```

**结论**：ρ ∈ [0, 0.85] 时，被动负载在 1% 平台精度下**不需要**独立复位，且输出能驱动阈值器件。当 ρ > 0.85 时，要么放宽平台精度，要么采纳 R-2 复位支路。

## 四、执行侧补充三点

### 4.1 幅度与阈值的联合限制（补充 v3 §4）

v3 §3.2 给出了代价"输出幅度很小"，但未量化对下游阈值器件的限制。补充如下：

设下游状态门（FET_z0/z1）的阈值为 θ_FET = 0.3 V（原语默认）。平台输出为：
```
v_∞ = V_H · x/(1+x) = (1−ρ)V_D · x/(1+x)
```

要求 v_∞ ≥ θ_FET，且平台精度 x ≥ (1−δ_p)/δ_p = 99（δ_p=0.01）：
```
(1−ρ)V_D · 99/100 ≥ 0.3
```

V_D=2.0 时，ρ ≤ 0.8485。

**因此，候选 P（被动负载，不加复位）的可行 ρ 区间为 [0, 0.85]，对应 R_S+R_L ∈ [R_L/0.85, +∞)**。这不是空集。

候选 R（R-2 复位支路）用于 ρ > 0.85、或 v_∞ 需要低于 0.3 V 但仍能被下一级放大器识别的场景（需要额外放大级，不在本轮）。
