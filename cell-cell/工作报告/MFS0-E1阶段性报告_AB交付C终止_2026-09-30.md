## 三、阶段 A：器件设计（COMPLETE）

### 3.1 设计单要点

**状态表**（7 态）：
- e（资格）：Capacitor + R_e，τ_e=0.3s（E0 冻结），新因果驱动（E-6）
- V_T（计时）：RC 充电 + 双阈值 FET，物理复位
- V_o（观察）：公共 later 输入，τ_o ≥ 1.44·T_hold
- v（读出节点）：V_D–R_S–G(V_o)–(v)–R_L，候选 P（被动）或 R（复位支路）
- v_ref（互补参考）：分压节点，R-3 路线 (a)
- P（结算脉冲）：V_T 越上阈触发
- w（载体）：Memristor，**跨周期、跨阶段保持**

**可行域**（修订后）：
- 候选 P（被动负载）：ρ ∈ [0, 0.85] 时 FEASIBLE
  - 比值约束：τ_off/τ_on = (1+x)/(1+ρx) ≥ ln(1/δ_c)/ln(1/δ_s) ≈ 4.6
  - 幅值约束：v_∞ = (1−ρ)V_D·x/(1+x) ≥ θ_FET = 0.3 V
  - ρ=0.6 时：比值 = 2.44（< 4.6，但可能满足实际清除要求），v_∞ = 0.792 V（✓）
- 候选 R（复位支路）：ρ > 0.85 时必需，k≈99

**D0 修订**（v3 评判）：
- 撤回原 E-1"普遍 99 倍"结论（隐含假设 ρ=0，不具普遍性）
- 改用 ρ 相关公式 + 幅度约束联合判据
- R-2 不是无条件必需，仅在 ρ > 0.85 时采纳

### 3.2 数学核验

v3 全部公式已独立复算，5 项全部一致：
- τ_off/τ_on 公式 ✓
- 反例（ρ=0.99 → 比值 1.01）✓

## 五、阶段 C：短程映射（TERMINATED）

### 5.1 设计

**目标**：9 点（p ∈ {0.2, 0.5, 0.8}，r ∈ {0.95, 1.0, 1.05}）× 3 档 dt（0.001/0.0025/0.005）× 50 次 Brier，选满足 δ_sim < 0.015 的最粗 dt。

**策略**：先跑 pilot_speed_test（1 点 × 3 档 × 50 次），外推成本，判断是否继续。

### 5.2 pilot 测速结果

**实测**（p=0.5, r=1.0, dt=0.001）：
- 单次耗时：**11.5 秒**
- 步数：308,500 步（T_total = 308.5s / dt = 0.001s）
- pilot 总耗时：50 次 × 3 档 = **28.75 分钟**

**外推完整映射**：
- 总试验次数：9 点 × 3 档 × 50 = **1,350 次**
- 预计耗时：1,350 × 11.5s = **258.75 分钟**（4.3 小时）
- 预算上限：120 分钟（主实验预算，v3 §8）
- **超预算倍数：2.15×**

### 5.3 终止判定

按 v3 §8 停止规则：
> 可行域空 / 修订用尽 / **预算耗尽** → 停止，交付已完成阶段

**判定**：2.15× > 2.0×（pilot 外推已超 2 倍预算） → **立即终止**，不执行完整映射。

**原因**：
1. 阶段 A 已警告"超预算 5.75~11.5 倍"（11.5~23.0 h vs 2 h）
2. T_settle = 300s（由 τ_on = 0.300s + 清除要求决定）过长
3. dt = 0.001s 过细（308,500 步/次）
4. N_trials = 50 次 × 9 点 × 3 档 = 1,350 次过多

**不可绕过的物理约束**：
- τ_on = R_L·C_s = 0.300s（E0 实测 τ_e，不可改）
- 清除要求 ln(1/δ_c) ≈ 4.6 个时间常数 → T_clear ≈ 1.4s
- 观察期 T_obs = 3.5s（写入可达窗）
- 预热期 T_warmup = 5s（past + later）
- 合计 **T_total ≥ 9.9s 物理时间**

### 5.4 可能的优化路径（未实施）

1. **降低 T_settle**：放宽 δ_c 从 0.01 → 0.05，或接受候选 R（复位支路，k≈99 倍加速）
2. **增大 dt**：直接用 0.005s（步数 ÷5），但需验证 δ_sim
3. **减少试验次数**：50 → 20（Brier 估计精度下降）
4. **减少点阵**：9 点 → 3 点（只取 p=0.5，r ∈ {0.95, 1.0, 1.05}）
5. **接受长墙钟**：用户批准 4~5 小时运行

**本轮未采纳**，按 v3 §8 交付 A+B。
